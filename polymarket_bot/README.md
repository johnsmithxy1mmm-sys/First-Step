# Polymarket Longshot Bot

Автономный бот для стратегии «лонгшотов»: массовые мелкие ставки на очень
дешёвые исходы (цена $0.001–0.01 за акцию). Каждая акция при победе исхода
платит $1: покупка по $0.01 даёт потенциал x100, по $0.005 — x200.

Это не «скупить всё дешёвое»: бот скорит кандидатов, заходит maker-ордерами
внутри спреда, сам снимает зависшие ордера, фиксирует прибыль на иксах и
параллельно ловит безрисковые арбитражи neg-risk событий.

## Чем он отличается от типового «купи дешёвое» бота

1. **Скоринг вместо слепой скупки.** Каждый кандидат получает балл 0..1:
   - *momentum* (вес 0.35) — цена исхода росла за сутки: кто-то накапливает;
   - *activity* (0.20) — всплеск суточного объёма: рынок проснулся;
   - *horizon* (0.15) — «сладкое» окно резолюции ~30 дней;
   - *liquidity* (0.15) — глубина рынка: дешёвую цену реально забрать;
   - *value* (0.15) — чем дешевле, тем больше иксов.
   Ставки размещаются в порядке скора, размер ставки масштабируется
   0.5x–1.5x от базового (`stake_scaling`).
2. **Maker-вход.** Вместо покупки по ask бот ставит свой ордер у бида
   (`entry_mode: maker`). На ценах 0.005–0.01 один тик экономии — это десятки
   процентов будущей выплаты. Хотите мгновенное исполнение — `taker`.
3. **Автофиксация прибыли.** Купили по 0.005, цена дошла до 0.06 (12x)?
   Бот продаёт половину (`take_profit_fraction`) — вложенное возвращено
   многократно, остаток позиции «едет бесплатно» до резолюции.
4. **Арбитраж neg-risk событий.** В событии с несколькими исходами (выборы
   и т.п.) побеждает ровно один. Если комплект «Yes всех кандидатов» стоит
   меньше $1 — это гарантированная прибыль. Бот сканирует такие окна каждый
   цикл (`arb_scan`) и умеет исполнять их автоматически (`arb_execute`,
   по умолчанию выключено — есть риск частичного входа).
5. **Гигиена ордеров.** Неисполненные лимитки старше `max_order_age_hours`
   снимаются автоматически — бюджет не замораживается.
6. **Telegram-уведомления.** Ставки, арбитражи, выигрыши к выводу — придут
   в чат, если задать `TELEGRAM_BOT_TOKEN` и `TELEGRAM_CHAT_ID`.

## ⚠️ Прочитайте перед использованием

- **Это не «бесплатные деньги».** Цена $0.01 — это оценка рынка, что
  вероятность исхода ~1%. Если рынок прав, 100 ставок по $15 в среднем дадут
  одну победу и просто вернут вложенное. Скоринг и maker-вход сдвигают
  математику в вашу пользу, но плюсовость не гарантируют. Единственная
  математически гарантированная часть — арбитражи, и они редки.
- **Хвостовые исходы часто дешевы заслуженно**: «метеорит упадёт на Париж» за
  $0.002 — это не x500, это почти гарантированные -100%.
- Юрисдикционные ограничения Polymarket — ваша ответственность. Ставьте
  только деньги, которые готовы полностью потерять.
- Приватный ключ передаётся только через переменную окружения и используется
  официальной библиотекой `py-clob-client` для подписи ордеров. Никому не
  показывайте его и не коммитьте в git.

## Установка

```bash
cd polymarket_bot
pip install -r requirements.txt
```

## Настройка ключей (только для реальной торговли)

```bash
export POLYMARKET_PRIVATE_KEY=0x...   # приватный ключ кошелька
# Если аккаунт создан через email или браузерный кошелёк на сайте Polymarket:
export POLYMARKET_FUNDER=0x...        # адрес депозита из настроек Polymarket
export POLYMARKET_SIGNATURE_TYPE=1    # 1 = email (Magic), 2 = браузерный кошелёк, 0 = свой EOA
# Опционально — уведомления в Telegram:
export TELEGRAM_BOT_TOKEN=123:abc     # токен от @BotFather
export TELEGRAM_CHAT_ID=123456789     # ваш chat id (узнать у @userinfobot)
```

На балансе (Polygon) должен быть USDC. Для аккаунтов, созданных через сайт,
разрешения (allowances) уже выставлены; для «сырого» EOA (signature_type=0)
нужно один раз выдать allowance на контракты биржи — проще всего сделав одну
ставку руками через интерфейс Polymarket.

## Команды

```bash
# 1. Посмотреть кандидатов со скорами (ничего не покупает, ключи не нужны)
python -m polymarket_bot scan --max-price 0.01

# 2. Один цикл без денег: что бот купил бы, по каким ценам, какие арбитражи видит
python -m polymarket_bot run --stake 15 --budget 1500

# 3. Один реальный цикл (спросит подтверждение; --yes чтобы не спрашивал)
python -m polymarket_bot run --stake 15 --budget 1500 --live

# 4. АВТОПИЛОТ: крутится сам, цикл каждые auto_interval_min минут
python -m polymarket_bot auto --live --yes --config polymarket_bot/config.json

# 5. Сканер арбитражей отдельно
python -m polymarket_bot arb

# 6. История ставок и позиции с PnL
python -m polymarket_bot history
python -m polymarket_bot positions --address 0xВАШ_АДРЕС
```

Все параметры удобнее держать в конфиге: `cp config.example.json config.json`
и запускать с `--config polymarket_bot/config.json`.

## Автозапуск 24/7

Вариант A — просто оставить в tmux/screen:

```bash
tmux new -s polybot
python -m polymarket_bot auto --live --yes --config polymarket_bot/config.json
```

Вариант B — cron, один цикл в полчаса (`--once` завершает процесс после цикла):

```cron
*/30 * * * * cd /path/to/First-Step && POLYMARKET_PRIVATE_KEY=... \
  python -m polymarket_bot auto --live --yes --once >> polymarket_bot/data/cron.log 2>&1
```

Журнал циклов автопилот пишет в `polymarket_bot/data/auto.log`, все ставки —
в `polymarket_bot/data/bets.json` (бюджет и дубли учитываются между запусками).

## Что происходит в одном цикле автопилота

1. **Гигиена** — снять лимитки старше `max_order_age_hours`, вернуть бюджет.
2. **Ставки** — скан рынков → фильтры → скоринг → maker-ордера в пределах
   `total_budget_usd` и `daily_budget_usd`. Дубли по токенам не ставятся.
3. **Сопровождение** — тейк-профит на `take_profit_multiple` иксах, поиск
   выигрышей со статусом «можно забрать» (redeem делается кнопкой на сайте).
4. **Арбитраж** — скан neg-risk событий; при `arb_execute: true` — исполнение
   с перепроверкой по реальным стаканам.
5. **Сводка** — в консоль, в `auto.log` и в Telegram.

Каждый шаг изолирован: упавший скан не останавливает сопровождение позиций,
5 ошибок ордеров подряд прерывают размещение (кончился баланс/allowance),
а сам цикл повторяется по расписанию, что бы ни случилось.

## Ключевые настройки (config.example.json)

| Параметр | Смысл |
|---|---|
| `max_price` | максимальная цена исхода ($0.01 = потенциал x100) |
| `stake_usd`, `stake_scaling` | базовая ставка и масштабирование 0.5x–1.5x по скору |
| `total_budget_usd`, `daily_budget_usd` | общий и дневной лимиты трат |
| `min_liquidity_usd`, `min_volume_usd` | отсев пустых рынков |
| `min/max_days_to_resolution` | окно резолюции |
| `include_keywords`, `exclude_keywords` | фильтры по тексту вопроса |
| `min_score` | минимальный скор кандидата (0 = брать всех по порядку скора) |
| `entry_mode` | `maker` (дешевле) / `taker` (мгновенно) |
| `auto_interval_min` | период цикла автопилота |
| `max_order_age_hours` | когда снимать зависшие ордера |
| `take_profit_multiple`, `take_profit_fraction` | на скольких иксах и какую долю фиксировать |
| `arb_scan`, `arb_min_edge`, `arb_execute`, `arb_stake_usd` | арбитражный модуль |
