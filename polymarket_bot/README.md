# Polymarket Longshot Bot

Бот для стратегии «лонгшотов»: массовые мелкие ставки на очень дешёвые исходы
(цена $0.001–0.01 за акцию). Каждая акция при победе исхода платит $1, то есть
покупка по $0.01 даёт потенциал x100, по $0.005 — x200.

Логика: бот сканирует все активные рынки Polymarket, отбирает исходы дешевле
порога на ликвидных рынках, проверяет реальный стакан и раскладывает бюджет
равными ставками лимитными ордерами.

## ⚠️ Прочитайте перед использованием

- **Это не «бесплатные деньги».** Цена $0.01 — это оценка рынка, что вероятность
  исхода ~1%. Если рынок прав, 100 ставок по $15 в среднем дадут одну победу и
  просто вернут вложенное — а спред, проскальзывание и невыкупленные ордера
  сдвигают математику в минус. Стратегия плюсовая только если вы отбираете
  исходы, чью вероятность рынок **недооценивает** (для этого есть фильтры по
  ключевым словам и ручной режим `scan`).
- **Хвостовые исходы часто дешевы заслуженно**: «метеорит упадёт на Париж» за
  $0.002 — это не x500, это почти гарантированные -100%.
- Юрисдикционные ограничения Polymarket (включая блокировку ряда стран) — ваша
  ответственность. Ставьте только те деньги, которые готовы полностью потерять.
- Приватный ключ передаётся только через переменную окружения и используется
  официальной библиотекой `py-clob-client` для подписи ордеров. Никому не
  показывайте его и не коммитьте в git.

## Установка

```bash
cd polymarket_bot
pip install -r requirements.txt
```

## Настройка ключей (только для реальной торговли)

```bash
export POLYMARKET_PRIVATE_KEY=0x...   # приватный ключ кошелька
# Если аккаунт создан через email или браузерный кошелёк на сайте Polymarket:
export POLYMARKET_FUNDER=0x...        # адрес депозита из настроек Polymarket
export POLYMARKET_SIGNATURE_TYPE=1    # 1 = email (Magic), 2 = браузерный кошелёк, 0 = свой EOA
```

На балансе (Polygon) должен быть USDC. Для аккаунтов, созданных через сайт,
разрешения (allowances) уже выставлены; для «сырого» EOA (signature_type=0)
нужно один раз выдать allowance на контракты биржи — проще всего сделав одну
ставку руками через интерфейс Polymarket.

## Команды

```bash
# 1. Посмотреть кандидатов (ничего не покупает, ключи не нужны)
python -m polymarket_bot scan --max-price 0.01

# 2. Прогон без денег: покажет, что и по каким ценам бот бы купил
python -m polymarket_bot run --stake 15 --budget 1500

# 3. Реальные ставки (спросит подтверждение; --yes чтобы не спрашивал)
python -m polymarket_bot run --stake 15 --budget 1500 --live

# 4. История ставок бота
python -m polymarket_bot history

# 5. Текущие позиции и PnL (в т.ч. выигрыши, готовые к выводу)
python -m polymarket_bot positions --address 0xВАШ_АДРЕС
```

Все параметры можно вынести в конфиг: `cp config.example.json config.json`
и запускать с `--config polymarket_bot/config.json`.

## Ключевые настройки (config.example.json)

| Параметр | Смысл |
|---|---|
| `max_price` | максимальная цена исхода ($0.01 = потенциал x100) |
| `stake_usd` | размер одной ставки |
| `total_budget_usd` | общий лимит: бот помнит потраченное между запусками |
| `min_liquidity_usd`, `min_volume_usd` | отсев пустых рынков, где дешёвую цену не купить |
| `min/max_days_to_resolution` | окно резолюции: не морозить деньги на годы |
| `include_keywords`, `exclude_keywords` | фильтры по тексту вопроса (напр. только "bitcoin", без "earthquake") |
| `max_bets_per_market` | не больше N ставок на один рынок |
| `verify_orderbook` | сверять реальный ask в стакане перед ставкой |

## Как это работает внутри

1. `gamma.py` — постранично выгружает активные рынки из Gamma API.
2. `strategy.py` — фильтрует: цена в диапазоне, ликвидность/объём, дата
   резолюции, ключевые слова; сортирует по ликвидности.
3. `clob.py` — берёт лучший ask из стакана CLOB; если реальная цена выше
   порога, кандидат пропускается. Ордера — лимитные GTC через `py-clob-client`
   (поддержаны neg-risk рынки и прокси-кошельки).
4. `storage.py` — пишет каждую ставку в `data/bets.json`: дубли не ставятся,
   бюджет учитывается между запусками.
